# PhotoCraft

**一个跑在你浏览器里的图像编辑器。** 纯 Rust 从零重写的开源「类 Photoshop」：图层、蒙版、
调整图层、图层样式、文字、矢量，以及真实的 PSD 读写。

这个飞牛应用把它的官方 WebAssembly 版本托管到你的 NAS 上：**NAS 只发静态文件**，所有编辑
运算都在你打开页面的那台设备（电脑/手机）的浏览器里完成。

## 适合拿来做什么

- 在任意一台设备上打开就能修图，不装客户端；
- 打开本机的 PSD / TIFF / PNG / JPEG / EXR 等（含 iPhone 的 HEIC 只读），分层编辑后导出；
- 自带中文字体，文字工具可以直接排中文；
- 断网可用：它不联任何云，编辑与保存全在你本机。

## 用起来

1. 装好后点桌面图标，或打开 `http://<NAS-IP>:28200/`。
2. 编辑器在你的浏览器里启动（首次要下载约 14 MB 的 WebAssembly，之后走缓存）。
3. 「文件 → 打开」选你**这台设备**上的图片，编辑完「导出」下载回本地。

> 想让它更快？用局域网 **https** 入口打开可启用 WebGPU 加速；明文 `http` 会退化为
> WebGL2，功能一样但较慢。

## 边界（很重要）

- **文件不经过 NAS**：读写的都是你当前设备上的文件，NAS 上不会保存任何图片或文档。
- **没有登录**：同网段能访问该端口的人都能打开这个编辑器页面（他看到的是他自己本机打开的
  文件）。请不要把 28200 端口直接映射到公网。
- 上游项目仍处 alpha 阶段，功能面很广但不是 Photoshop 的完全替代品。

## 端口与权限

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 端口 | `28200` | 安装向导可改，应用设置页也能改 |
| 监听 | `0.0.0.0` | 想只给本机/反代用，可在设置页改成 `127.0.0.1` |
| 运行身份 | `package`（普通应用账号） | 只读发文件，不需要 root |

## 卸载

默认「保留配置」（端口与日志保留，重装沿用）；也可选「完全卸载」删除运行期状态。
两种方式都不涉及你的图片——NAS 上本来就没有存任何文件。
