# Cloudflare 优选

给走 Cloudflare 的域名挑一条**更快、且真的能服务这个域名**的线路，并写进飞牛本机的 `/etc/hosts`。

同一个 Cloudflare 域名，官方默认给你回的那两个 IP 未必离你最近：实测见过落点在阿姆斯特丹、
首字节 2.7 秒，换一条洛杉矶线路变 0.3 秒。这个工具把候选线路逐个测一遍，挑出对你最快的写进系统解析表。

## 和「测速类工具」不一样的地方

- **能连上 ≠ 能服务你**：随便拿一个 Cloudflare IP 去测速它都会响应，但可能返回
  `403 error code: 1034`（这个边缘不服务你的 zone）。本工具用**你的真实域名**做 SNI + Host
  去请求 `/cdn-cgi/trace`，只有 200 且能读出机房代码才算可用，1034 直接淘汰。
- **排名看打开速度，不看带宽**：对筛出来的候选做页面级复测，取中位首字节耗时排序。
- **一个域名一张卡片**：不同域名的可用集合与速度可以完全不同，各测各的、互不影响。

## 用起来

1. 打开面板（桌面图标，或 `http://<NAS-IP>:26890/`）。
2. 「添加域名」：填你挂在 Cloudflare 后面的域名（比如 `app.example.com`）。
3. 点该域名的「重新测速」：先粗筛可用边缘，再对前 6 名做页面级复测。
4. 看排名表（最多 6 条，按打开速度）：点「应用优选」写入前 3 条（主 + 2 备），
   或者点某一行单独应用那一条 IP。
5. 「系统 hosts」卡片里能看到写入的每一行、以及**是否真的生效**（拿域名做一次真实解析比对）；
   不满意可以逐条删除，或者整块「还原默认」。

整个过程只改自己标记的受管区块，块外内容一字不动；没点「应用」之前一律只是预览。

## 端口与权限

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 面板端口 | `26890` | 安装向导可改，应用设置页也能改 |
| 监听范围 | `0.0.0.0` | 想只给本机或反代用，在设置页改成 `127.0.0.1` |
| 写 hosts | 允许 | 关掉 = 只能测速预览，不改系统文件 |
| 运行身份 | root | 改 `/etc/hosts` 必须 root；面板无登录口令，**请勿把端口暴露到公网** |

## 数据与卸载

配置、测速状态、历史记录、hosts 备份都在应用数据目录（`/vol1/@appdata/CloudflareIP/`）。
卸载时可选「保留配置」——域名列表与历史都留着，重装即沿用。

**卸载不会动 `/etc/hosts`**：那里是你当前生效的系统解析。想彻底回到系统默认，
请在卸载前打开面板，点「系统 hosts」里的「还原默认」。

## 命令行

装上之后终端里也能直接用（同一份二进制）：

```bash
cloudflareip help                                   # 看全部参数
cloudflareip probe -domain app.example.com -top 8    # 只测速、打印候选表
sudo cloudflareip probe -domain app.example.com -json /tmp/cf.json
```
